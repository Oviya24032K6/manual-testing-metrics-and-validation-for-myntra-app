## 📌 Project Overview

This repository contains the complete **Manual Testing Documentation** for the **Myntra E-Commerce Application** — an online fashion shopping platform. The project covers functional testing of the application's major features, including test case design, execution, defect logging, and test metrics & analysis.

**Application Type:** E-Commerce / Online Fashion Shopping Application
**Testing Type:** Manual Testing
**Testing Approach:** Functional (Black-Box) Testing

---

## 🎯 Testing Objectives

- Verify that the major features of the Myntra application work as expected
- Identify functional defects and unexpected behaviour
- Verify that the application meets the expected requirements
- Create and execute test cases for the selected features
- Record and report identified defects with appropriate severity and priority
- Measure testing results using standard test metrics
- Analyze test results to identify areas needing further testing or improvement

## 📊 Metrics Formulas Used

| Metric | Formula |
|---|---|
| Test Coverage | (Requirements Tested ÷ Total Requirements) × 100 |
| Test Execution % | (Executed Test Cases ÷ Total Test Cases) × 100 |
| Pass Rate | (Passed Test Cases ÷ Executed Test Cases) × 100 |
| Fail Rate | (Failed Test Cases ÷ Executed Test Cases) × 100 |
| Defect Density | Number of Defects ÷ KLOC |
| Defect Closure Rate | (Closed Defects ÷ Total Defects) × 100 |
